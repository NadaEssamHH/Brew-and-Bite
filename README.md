# ☕ Brew & Bite — Artisanal Coffee & Bakery Web App

> A modern, responsive web application for an artisanal coffee shop and bakery, featuring component-driven UI architecture, product filtering, dynamic cart management, and seamless menu ordering.

---

## 🚀 Tech Stack

- **Frontend:** React.js, TypeScript
- **Styling:** Tailwind CSS / CSS Modules
- **Build Tool:** Vite
- **Version Control:** Git & GitHub
